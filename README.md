# Полеты к Gateway — Frontend

Этот репозиторий содержит фронтенд-проект, посвященный полетам к Gateway. Он предоставляет интерфейс для взаимодействия с пользователем, включая загрузку данных, рецензирование и анализ решений, а также интеграцию с серверной частью для проверки информации.

## Репозитории
- **[Frontend (вы здесь)](https://github.com/Bizerman/gateway-mission-frontend)** – клиентская часть проекта
- **[Backend](https://github.com/Bizerman/gateway-mission-backend)** – серверная часть проекта

## Ветки
- **[SPA](https://github.com/Bizerman/gateway-mission-frontend)** – разработка базового `SPA` на React
- **[Redux](https://github.com/Bizerman/gateway-mission-frontend/tree/Redux)** – добавление менеджера состояний `Redux Toolkit`
- **[Pwa](https://github.com/Bizerman/gateway-mission-frontend/tree/PWA)** – добавление возможности работы в режиме `PWA` 
- **[Pwa](https://github.com/Bizerman/gateway-mission-frontend/tree/gh-pages)** – добавление возможности работы в режиме `GitHub Pages`
- **[Tauri](https://github.com/Bizerman/gateway-mission-frontend/tree/Tauri)** – создание простого нативного приложения на Tauri
- **[Engenier interface](https://github.com/Bizerman/gateway-mission-frontend/tree/Engenier-Interface)** – завершение интерфейса `пользователя` в `React`
- **[Moderator interface](https://github.com/Bizerman/gateway-mission-frontend/tree/Operator-Interface)** – завершение интерфейса `модератора` в `React`

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Bizerman/gateway-mission-frontend
cd gateway-mission-frontend
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск проекта
```bash
npm run dev
```

## Основные возможности
- Загрузка данных о полетах и их анализ
- Рецензирование решений для миссий
- Интеграция с серверной частью для проверки и анализа информации
- Удобный интерфейс для взаимодействия с пользователем
